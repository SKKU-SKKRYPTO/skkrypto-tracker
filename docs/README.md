# 온체인 트랜잭션 추적 시스템

주소·Tx Hash에서 출발해 토큰 이동을 그래프로 추적하고, 각 연결의 거래 근거를 확인하는 읽기 전용 도구입니다.

```txt
데이터 수집 → 전송 정규화 → 경로·패턴 분석 → 근거 확인 → 결과 JSON
```

> 기획안 기준 초안 (2026-10-27). 기획이 바뀌면 이 문서를 함께 고칩니다.

## 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| 목표 | 지정한 데이터 범위에서 주소 간 토큰 이동 경로와 분석 근거를 제시한다 |
| 구성 | 4인 팀 개발 + 교육용 실습 문제 3개 |
| 대상 | Base Sepolia(chainId `84532`), 지정 ERC-20 1종, 고정 블록 구간 |
| 결과물 | 추적 웹앱, 수집기, 분석 엔진, 재현 가능한 데이터셋, 문제·정답, 실행·검증 문서 |
