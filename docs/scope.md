# 개발 범위

P0를 모두 끝낸 뒤에만 P1을 시작합니다. 일정이 부족하면 P1부터 빼고 작은 데이터셋의 P0 정확성에 집중합니다.

## P0 — 필수

- Transfer 로그 수집·정규화·중복 제거, 중단 후 재개와 데이터셋 무효화 처리
- 주소·Tx Hash 검색, 데이터셋 버전·수집 범위·상태 표시
- 송신·수신 방향의 1~3 hop 그래프와 두 주소 사이의 시간순 후보 경로
- 그래프·전송 목록·거래 상세 동기화, 실제 거래의 Explorer 링크
- 분산(FAN_OUT)·합류(FAN_IN) 패턴의 기준·근거·오탐 가능성 표시
- 분석 조건·버전·근거·한계를 담은 JSON 내보내기
- 오프라인 Fixture, 실제 테스트넷 Snapshot, 실습 문제 3개

## P1 — P0 완료 후 선택

- 최상위 ETH 전송, 두 번째 ERC-20
- 추가 패턴, 수동 라벨
- 시간 필터 고도화
- CSV·PNG 내보내기, 메모
- 거래 근거를 인용하는 AI 요약

## 제외

- 전 체인·전체 이력
- 실시간 상시 수집
- 브릿지·DEX 자산 변환 추론
- 내부 트랜잭션 전체 복원
- 실명 추정, 자동 AML·범죄 판정
- 메인넷 실자산 실습
- 송금·동결·회수
