# 사용자 흐름

사용자는 범위를 정하고, 시작점을 고르고, 그래프를 넓히며 근거를 확인한 뒤 결과를 JSON으로 저장합니다.

1. **범위 선택** — 데이터셋·버전·토큰·블록 구간을 확인한다.
2. **시작점 선택** — 주소를 입력하거나, Tx Hash에 들어 있는 Transfer 중 하나를 고른다.
3. **탐색** — 방향·깊이·필터로 그래프를 확장하거나 두 주소 사이의 경로를 찾는다.
4. **근거 확인** — 그래프·표·상세에서 금액, Tx Hash, 블록·거래·로그 위치를 확인한다.
5. **해석·저장** — 패턴 기준과 분석 한계를 확인하고 JSON으로 내보낸다.

## 표시 원칙

- 빈 결과는 "선택한 수집 범위에서 관측되지 않음"으로 표시한다.
- 탐색 상한으로 결과가 잘렸으면 잘린 이유를 보여 주고, 연결이 없다고 단정하지 않는다.
- 경로와 패턴은 관측 사실과 후보로만 표현한다. 범죄 여부나 특정 원금의 도착을 단정하지 않는다.
- Fixture(합성 데이터)는 합성임을 표시하고 실제 Explorer 링크를 만들지 않는다.
- 그래프 없이 표와 키보드만으로도 같은 근거를 확인할 수 있어야 한다.
